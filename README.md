# O Fascinante Universo dos Gatos · A Arte do Ronrom

Website editorial elegante dedicado ao universo felino, serenidade, curiosidades e bem-estar dos gatos.

## Como publicar no GitHub Pages:
1. Suba este arquivo `index.html` e a pasta `assets` para o seu repositório no GitHub.
2. No repositório no GitHub, vá em **Settings** > **Pages**.
3. Em **Branch**, selecione `main` (ou `master`) e clique em **Save**.
4. Em instantes o seu site estará no ar gratuitamente!
